LAB 6 · PRIVATE ACCESS

Provision ZPA Infrastructure

Everything so far has been about internet-bound traffic. Now you build the piece that lets ZPA reach into the datacenter without opening a single inbound firewall port: a provisioning key generated in the portal, carried over SSH to a Linux VM, and an App Connector that phones home to register itself.

Lab 6: Provision ZPA Infrastructure

OVERVIEW

Scenario: Safemarch Corporation is preparing to launch internal applications and requires secure, policy-driven connectivity without exposing those applications to the internet. As a Zscaler administrator, you deploy and provision ZPA App Connectors across data centers and cloud platforms. These App Connectors provide encrypted connectivity through the Zero Trust Exchange (ZTE) while keeping internal apps protected.

  • Deploy and provision an App Connector using a provisioning key and certificate.
  • Activate the App Connector, enabling secure communication with the ZPA infrastructure.
  • Validate the connection and ensure the App Connector is functioning correctly.
Time: ~25 minutes
Environment: Simulated tenant — Corp: Win Svr 2016 + Corp: APP Connector

Note: All tasks in this lab (6.1–6.2) are completed using the simulated lab exercises. The instructions below are for reference only; you perform the steps within the simulated lab environment.

Task 6.1 Provision an App Connector ▾

In this task, you configure the App Connector by creating a provisioning key and registering it in the ZTE.

Note: The App Connector has been pre-installed with the appropriate network, DNS, and NTP configuration. You activate it by providing the provisioning key created in the Experience Center Portal. For more details, see Configuring App Connectors.

  1. Access the ZPA Admin Portal. On the Corp: Win Svr 2016 VM, log in with PATRAINING\Administrator / Admin-123!. Navigate to the Experience Center Landing Page (https://console.zscaler.com/) and authenticate with the Student account.

    Note: Use the Windows 2016 server to access the Experience Center Portal, since you need to upload the provisioning key through WinSCP.

  2. Configure the App Connector — from the Experience Center, navigate to Infrastructure > Private Access > App Connector Groups.
    Infrastructure > Private Access > App Connector Groups.
  3. From Add App Connector Group, select Add App Connector Group and configure:
    • Name: OnPrem
    • Status: Enabled
    • Description: optional
    • Signing Certificate: Connector
    • DNS Settings (IPv4/IPv6): leave as default
    • Location: NYC, NY, USA
    Select Next. Version Profile Configuration: leave as default. App Connector Software Update Schedule: Sundays at 00:30. Select Save.
    Version Profile default, Update Schedule Sundays at 00:30.
    App Connector Group "OnPrem" saved.
  4. From App Connector Keys, select Add App Connector Keys and configure:
    • Group: OnPrem
    • Name: OnPrem
    • Maximum Reuse Count: 4
    • Signing Certificate: Connector
    Select Save.
    App Connector Keys — Maximum Reuse Count 4, Signing Certificate: Connector.
  5. Save the provisioning key. Select App Connector Provision Keys and select the Copy icon to copy the key.
    App Connector Provision Keys — copy the key.
    Right-click an empty area of the Desktop, select New > Text Document, and name it provision_key.

    Note: Remove the .txt extension if it appears, so the file name is exactly provision_key with no suffix.

    Open the file, paste the OnPrem App Connector provisioning key you copied, then select File > Save and close Notepad.

Task 6.2 Activate the App Connector ▾

In this task, you activate the App Connector and ensure secure traffic flow to ZPA.

  1. Configure the App Connector VM (Corp: APP Connector) — log in with admin / zscaler. Start the SSH daemon so you can connect with WinSCP:
    sudo systemctl start sshd
    password: zscaler. Verify SSH is running:
    sudo systemctl status sshd
    Confirm status is active (running).
  2. Transfer the provisioning key. On Corp: Win Svr 2016, open WinSCP and configure the session:
    • IP Address: 10.0.0.4
    • Port: 22
    • Username: admin
    • Password: zscaler
    WinSCP — session to 10.0.0.4:22.
    WinSCP connected to Corp: APP Connector.
  3. In WinSCP, navigate to the key file: go to C:\Users\Administrator\Documents\"*" and select Browse, select Desktop, and select OK — confirm Desktop is selected. Right-click provision_key and select Upload, or drag and drop from left to right panel.
    Right-click provision_key on the Desktop and Upload.
    Verify the file is uploaded and close WinSCP.
  4. Activate the App Connector. You should see a prompt similar to admin@zpa-connector ~]$.

    Note: The ~ indicates you are in your home directory, /home/admin. After uploading provision_key via WinSCP, it lands in the admin home directory by default.

    Verify your current directory:
    pwd
    Expected output: /home/admin. List files:
    ls
    Expected output: provision_key.
  5. Activate the App Connector — stop the connector service:
    sudo systemctl stop zpa-connector
    Copy the provisioning key to the directory:
    sudo cp provision_key /opt/zscaler/var/

    Note: Ensure the trailing slash (/) after var. Its absence can cause service startup failures.

    Copy the provisioning key into /opt/zscaler/var/.
  6. Confirm the file:
    sudo ls /opt/zscaler/var/
    Confirm provision_key is present in /opt/zscaler/var/.
    Restart the service:
    sudo systemctl start zpa-connector
    Enable the service to start on boot:
    sudo systemctl enable zpa-connector
    Verify the service is running:
    sudo systemctl status zpa-connector

    Note: Expected result — the App Connector is active and connected to the ZPA infrastructure. You should see the .pem key and certificate files as further confirmation.

    zpa-connector service — active (running).
  7. Optional recovery (only if the connector status fails or is red): stop the service (sudo systemctl stop zpa-connector), clear the var directory (sudo find /opt/zscaler/var -mindepth 1 -delete), confirm provision_key still exists in /home/admin (re-upload via WinSCP if necessary), re-copy the key (sudo cp provision_key /opt/zscaler/var/), start the service (sudo systemctl start zpa-connector), and check status (sudo systemctl status zpa-connector).
  8. Verify in the ZPA Admin Portal — on the Experience Center Landing Page (Corp: Win Svr 2016), navigate to Infrastructure > Private Access > App Connectors. Confirm the App Connector is listed.
    App Connectors — the OnPrem connector is listed.
  9. Update Status field — Success means the App Connector is running the latest software; Scheduled means an update will occur at the next update interval.
    Update Status — Success or Scheduled.

    Note: There is no need to wait for the App Connector to update. Continue with the lab and check back in a few minutes.

  10. Select the App Connector's name to expand details, including Host OS, PSE, Location, IP Addresses, and Uptime.
    App Connector detail — Host OS, PSE, Location, IP Addresses, Uptime.
