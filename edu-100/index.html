ⓘ Zero Trust Exchange in one minute — key terms
ZIdentityZscaler's unified identity platform — houses departments, user groups, users, IdP integrations (OIDC/SAML), and administrative/service entitlements shared across ZIA, ZPA, and ZDX.
ZIAZscaler Internet Access — cloud secure web gateway enforcing firewall, SSL inspection, URL filtering, and cloud app control on all internet-bound traffic.
ZPAZscaler Private Access — zero-trust access to internal applications via App Connectors and App Segments. Users connect to apps, never to the network.
ZDXZscaler Digital Experience — end-to-end performance monitoring across networks, applications, and devices, surfaced through Incident, Application, and User dashboards.
Zscaler Client Connector (ZCC)Lightweight endpoint agent that forwards user traffic to the Zero Trust Exchange for ZIA, ZPA, and ZDX enforcement.
App ConnectorLightweight VM deployed near internal applications that creates outbound-only connections to ZPA, exposing apps without opening inbound firewall ports.
Read-Only Tenant (SDC)A shared, production-like Zscaler tenant provided via Solutions Demo Center credentials — used to review real-world configurations, dashboards, and logs without admin rights.
