EDU-280 · ハンズオンラボ

Zscaler Zero Trust Branch

高可用性を備えた Zero Trust Branch デバイスを展開するハンズオンラボ — セグメンテーション、ポリシーベースルーティング、DNS セキュリティ、監視、そして Ransomware Kill Switch

ⓘ Zero Trust Branch を1分で — 主要用語
ZTBZscaler Zero Trust Branch デバイス — 支社に Zero Trust セグメンテーションとセキュアな Direct Internet Access をもたらす。アクティブ／スタンバイの HA ペアで展開。
DIADirect Internet Access — 各 ZTB デバイスが Zero Trust Exchange 経由でインターネットに到達するための WAN アップリンク。
MacrosegmentationVLAN／セグメント間のトラフィックを制御するポリシー（東西方向）— 例: VLAN10 → VLAN20 をブロック。
MicrosegmentationVLAN 内のトラフィックを制御するポリシー — 例: VLAN30 上で OT1 → OT2 をブロック。
PBRPolicy-Based Routing — 選択したトラフィック（SaaS、ICMP）を既定ではなく特定の経路に誘導する。
Ransomware Kill Switchインシデント時に横方向の拡散を封じ込める迅速なブロックモード（例: プライベートサブネット間の SSH）。
