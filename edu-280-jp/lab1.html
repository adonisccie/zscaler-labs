ラボ1 · EDU-280

Zero Trust Branch デバイスインターフェース構成

支社をプロビジョニングします。Site を追加し、HA のためにアクティブとスタンバイの ZTB デバイスをアクティベートし、サイトレベル設定と App Connector を構成して、すべての LAN VLAN とセカンダリ WAN インターフェースを構築します。

⚙ ラボ設定
管理者ログイン: pod##-student@<受講者FQDN> サイト名: POD##-Student-Lab App Connector: pod##StudentAppC

ラボ1: Zero Trust Branch デバイスインターフェース構成

プロビジョニング

Zero Trust Branch デバイス（物理／仮想）は、Zscaler Zero Trust Exchange (ZTE) を活用して支社トラフィックを Zscaler サービスへ転送します。このラボでは、Experience Center を通じて2台の仮想 ZTB デバイスの構成を編集します。（物理と仮想の構成は同一です。）

Zero Trust Branch プロビジョニングテンプレートを完成させます。

  • Templates — デフォルトテンプレートは全サイト用に vm-ha-edu280 としてクローンされています
  • Sites — アクティブ／スタンバイユニットをオンボードします
  • Device Details — System Settings、WAN DNS、App Connector。GE2 WAN インターフェースと GE6/GE7/GE8 LAN インターフェースを構成します
  • App Connector — 一部事前プロビジョニング済み。POD 用のキーが既に存在します
コース: EDU-280
版: 2.2 · 2026年2月
プラットフォーム: Skytap + Zscaler Experience Center

HA ペア = ZTB-1 (Active) + ZTB-2 (Standby)、フェイルオーバーは ge4 の VRRP 経由。デバイスコンソールログイン: admin / a!rg@p。WAN = ge1/ge2 で DHCP。LAN ゲートウェイ: VLAN10 = 10.1.10.1 (ge6)、VLAN20 = 10.1.20.1 (ge7)、VLAN30 = 10.1.30.1 (ge8) — いずれも /24、オンボックス DHCP レンジ .20–.30。ステータスは約15分後に Post-update → Active/Standby と遷移。App Connector = pod##StudentAppC。

ラボの進捗
クイックリファレンス ▲
Site
支社用の Experience Center オブジェクト（POD##-Student-Lab）— ZTB デバイス・インターフェース・ポリシーを保持。
Template (vm-ha-edu280)
全サイトに適用されるクローン済みプロビジョニングテンプレート。HA VM デバイス構成を定義。
Activation Code
デバイスごとのコード（Envelope アイコン）。ZTB コンソールに貼り付けて Airgap Gateway をアクティベート。
Active / Standby
ZTB-1 がトラフィックを転送、ZTB-2 は引き継ぎを待機。ステータスは Post-update → Active/Standby（約15分）。
VRRP (ge4)
HA インターフェースの Virtual Router Redundancy — フェイルオーバー時にスタンバイがゲートウェイ IP を引き継ぐ。
GE1 / GE2 (WAN)
2本の DIA WAN アップリンク。いずれも IP とネームサーバーに DHCP を使用。
GE6 / GE7 / GE8 (LAN)
それぞれ VLAN10 / VLAN20 / VLAN30 にマッピングされた LAN ポート。
VLAN IP
10.1.10.1 (VLAN10)、10.1.20.1 (VLAN20)、10.1.30.1 (VLAN30) — いずれも /24、オンボックス DHCP .20–.30。
NAT
サイトで有効化し、LAN サブネットが WAN アップリンク経由でインターネットに送出されるようにする。
App Connector Key
POD 用に事前作成されたプロビジョニングキー。Settings › ZPA で pod##StudentAppC を追加する際に貼り付け。
IPSec Tunnel
支社からの ZIA 転送トンネル。ZIA › IPSec Tunnels で Established/Up と表示される必要がある。
arp -a
構成済みインターフェースがデバイス上で有効であることを確認する Console コマンド。
