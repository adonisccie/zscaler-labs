ラボ8: Zero Trust Branch 環境のトラブルシューティングとデバッグ

トラブルシューティング

Zero Trust Branch 環境のトラブルシューティングとデバッグに使う基本コマンドを探索します。これらは、接続性の診断、ポリシー構成の検証、トラフィックフローの分析を、デバイスの Console から直接行うのに役立ちます。

  • インターフェース・ルート・ネイバーテーブルを読む（ip a、ip route、ip neighbour）
  • VyOS（VRRP）と StrongSwan（IPSec）コンテナを調べる
  • tcpdump でインターフェース上のライブ ICMP をキャプチャする
コース: EDU-280
版: 2.2 · 2026年2月
プラットフォーム: Skytap + Zscaler Experience Center
  • Infrastructure › Connectors › Edge › Zero Trust Branch › Sites に移動し、POD##-Student-Lab を選択します。
自分の POD サイトを開きます。
  • Console タブを開いて ip a と入力します — すべてのインターフェースと割り当て IP を表示します。
ip a — インターフェース + IP アドレス。
  • ip route と入力します — ルーティングテーブル（トラフィックがどの宛先に向けられるか）を表示します。
ip route — ルーティングテーブル。
  • アクティブユニットで ip neighbour と入力します — ネイバー／ARP テーブル（IP → MAC のマッピング）。

注意: ip neighbour と ip neighbor のどちらのスペルも受け付けられます。

ip neighbour — セグメントの ARP エントリ。
  • cat /etc/airgap/zcc/fqdn.txt | grep dcweb と入力します — FQDN dcweb.ztwan.lab（ラボ6でアクセスしたアプリ）を出力します。
FQDN ファイルをフィルタすると dcweb.ztwan.lab が現れます。
  • docker ps と入力します — 実行中のコンテナ（ID、名前、ステータス、イメージ）を一覧表示します。
docker ps — ネットワーク機能のコンテナ。
  • VyOS コンテナ内で VRRP を確認します:
    • docker exec vyos_container su - vyos sh -c "sudo /opt/vyatta/bin/vyatta-op-cmd-wrapper show vrrp"
VyOS コンテナ内の VRRP ステータス（HA 状態）。
  • StrongSwan 内の IPSec トンネルを確認します: docker exec strongswan ipsec status。
ipsec status — IPSec 接続／トンネル。
  • Skytap で Windows Server（VLAN10）を開きます。
  • コマンドプロンプトから連続 ping を実行します: ping 8.8.8.8 -t。
Windows Server（VLAN10）を開きます。
ping 8.8.8.8 -t — 安定した ICMP トラフィックを生成。
  • Console タブに戻り、パケットをキャプチャします: tcpdump -i ge6 icmp -c 20 — ge6（VLAN10 の LAN インターフェース）で 20 個の ICMP パケットをキャプチャします。
tcpdump -i ge6 icmp -c 20 で ge6 を通過する ping を確認。

完了: インターフェース・ルーティング・HA/IPSec コンテナのステータス・ライブトラフィックを Console から調べられるようになりました。次は Ransomware Kill Switch です。

覚えておこう
Console トラブルシューティングの階段: ip a（インターフェース/IP）→ ip route（ルーティング）→ ip neighbour（ARP/L2）。ZT800 は機能をコンテナで実行: VyOS = VRRP（show vrrp）、StrongSwan = IPSec（ipsec status）、docker ps で一覧。ライブ ping は tcpdump -i ge6 icmp -c 20 でトレース — ge6 = VLAN10 の LAN インターフェース。cat /etc/airgap/zcc/fqdn.txt | grep dcweb で dcweb.ztwan.lab が判明。

ラボの進捗
クイックリファレンス ▲
Console タブ
サイトビュー内の ZT800 のシェル — ip/docker/tcpdump コマンドを実行する場所。
ip a
すべてのインターフェースとその IP アドレス／ステータスを表示。
ip route
ルーティングテーブルを表示 — トラフィックがどの宛先に向けられるか。
ip neighbour
ARP／ネイバーテーブル（IP → MAC）を表示。"neighbor" のスペルも可。
docker ps
実行中のコンテナを一覧 — ZT800 のネットワーク機能はコンテナで動作。
VyOS コンテナ
ルーティング/VRRP 機能。show vrrp が HA（アクティブ/スタンバイ）状態を報告。
StrongSwan コンテナ
IPSec 機能。ipsec status が ZIA へのトンネルステータスを表示。
tcpdump -i ge6 icmp
ge6（VLAN10 LAN インターフェース）上の ICMP のライブキャプチャ — 実際の ping をトレース。
dcweb.ztwan.lab
データセンター Web アプリの FQDN。/etc/airgap/zcc/fqdn.txt に格納。
