Zscaler Zero Trust Branch

Build a Zero Trust Branch (ZTB 8.1.x) end to end — HA site, segmentation, DTLS to ZIA, ZPA access, policy-based routing, DNS policy and operational troubleshooting.

ⓘ Zero Trust Branch in one minute — key terms
ZTB / ZTEZero Trust Branch — Zscaler’s branch gateway; Zero Trust Exchange — the Zscaler cloud platform.
HA / VRRPActive/Standby gateway pair; the protocol that elects the Active unit.
Macro / microsegmentationPolicy between VLANs; policy between devices on the same VLAN.
PBRPolicy-based routing — send selected traffic out a chosen path.
Z-Tunnel / DTLSAuto-provisioned ZIA tunnels over UDP 443 with TLS fallback.
Kill SwitchPre-staged emergency policy modes (Green → Red) applied in one action.
BEFORE YOU BEGIN
Your Pod, Values and Tools
Core labs 0–6 take about 3 hours 20 minutes; optional labs 7–11 are not counted in the 4-hour session

Welcome to the Zscaler Zero Trust Branch (EDU-280) hands-on lab. You play the network administrator for a company rolling out Zero Trust Branch (ZTB 8.1.x) to a branch office that hosts users, IoT devices and OT devices. Over the core labs you build the branch from scratch, protect traffic inside the branch, secure its internet and private-application access, and fine-tune how traffic and DNS are handled.

Core labs 0–6 take about 3 hours 20 minutes and fit inside the 4-hour session with time for questions. The optional labs go deeper into operations — monitoring, troubleshooting, incident response and resilience — and are not counted in the 4 hours.

Your pod

Every student has an identical pod: two ZTB gateways between the branch VLANs, two WAN links and the Zscaler Zero Trust Exchange.

Figure — Your pod. Subnet10 and Subnet20 use Network (/24) segmentation; Subnet30 uses Device (/32) so every OT device is isolated.

  • • Two virtual ZTB gateways — ZTB-1 (Active) and ZTB-2 (Standby), each with 2 WAN, 3 LAN, 1 HA and 1 management interface
  • • Subnet10 10.1.10.0/24 — Windows Server (10.1.10.10)
  • • Subnet20 10.1.20.0/24 — IoT Ubuntu host (10.1.20.10)
  • • Subnet30 10.1.30.0/24 — OT1 and OT2 Ubuntu hosts (10.1.30.x)
  • • WAN GE1 10.120.1.1 / .2, gateway .254
  • • WAN GE2 10.130.1.1 / .2, gateway .254
  • • Private DNS 10.73.50.20 / .21
  • • WAS DNS 1.1.1.1 / 8.8.8.8
  • • Corp Client PC with Zscaler Client Connector, outside the branch
