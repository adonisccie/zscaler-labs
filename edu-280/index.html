Zscaler Zero Trust Branch

Hands-on labs deploying Zero Trust Branch devices with High Availability — segmentation, policy-based routing, DNS security, monitoring, and a ransomware kill switch

ⓘ Zero Trust Branch in one minute — key terms
ZTBZscaler Zero Trust Branch device — brings Zero Trust segmentation and secure Direct Internet Access to a branch. Deployed as an active/standby HA pair.
DIADirect Internet Access — the WAN uplinks each ZTB device uses to reach the Internet via the Zero Trust Exchange.
MacrosegmentationPolicy controlling traffic between VLANs/segments (east-west) — e.g. block VLAN10 → VLAN20.
MicrosegmentationPolicy controlling traffic within a VLAN — e.g. block OT1 → OT2 on VLAN30.
PBRPolicy-Based Routing — steers selected traffic (SaaS, ICMP) down a specific path instead of the default.
Ransomware Kill SwitchRapid block mode (e.g. SSH between private subnets) to contain lateral movement during an incident.
