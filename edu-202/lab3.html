ZPA Log Streaming

ZPA Log Streaming Service (LSS) exports private access telemetry — user activity, app connector status, and audit events — to any SIEM over TCP/TLS. In this lab you deploy a dedicated Log Streaming Connector, configure a Log Receiver pointing at your SIEM VM, and verify that user activity logs arrive in real time.

Lab 3: ZPA Log Streaming

LAB 3

Scenario: You are an IT Engineer tasked with centralizing security monitoring by streaming private application access logs to an on-premises security information and event management (SIEM) system. Because the SIEM consumes syslog data from local hosts, you provision a dedicated App Connector and configure the Log Streaming Service (LSS) to send real-time user activity events to a local syslog server.

Time: ~20 minutes
Service: Zscaler Private Access (ZPA)
Task 3.1 Provision a Dedicated App Connector for Log Streaming ▾

In this task, you create a dedicated Log Streaming App Connector by creating a Log Streaming App Connector Group.

Note: This task gives high-level instructions because you performed these steps in Lab 2. If you need detailed guidance, refer to Task 2.1 and Task 2.2.

  1. Configure the App Connector Group.
    1. In the Experience Center, go to Infrastructure > Private Access > App Connector Groups.
    2. Select Add App Connector Group and enter the Name Log Streaming (follow the remaining steps as in Task 2.1). Select Save.
  2. Configure the App Connector.
    1. Launch the Corp Log Streaming Connector VM.
    2. Log in to the Corp Log Streaming Connector VM by clicking SSH in the left side panel to log in automatically.
    3. Alternatively, use the CON option to sign in to the VM with the following credentials to generate a new token:
      • Username: admin
      • Password: Zscaler1!
    4. To view the token, type: cat /etc/issue
  3. Use the CLI to regenerate a new authentication token by running the following commands:
    1. Stop the ZPA Connector service: sudo systemctl stop zpa-connector
    2. Switch to root user privileges: sudo su
    3. Delete the existing OAuth token files: rm -rf /opt/zscaler/var/*
    4. Restart the ZPA Connector service to generate a new OAuth token: sudo systemctl start zpa-connector
    5. View the new token: cat /etc/issue
  4. Update the token in the App Connector to deploy it.
    1. In the Experience Center landing page (Corp Client PC 1), go to Infrastructure > Private Access > App Connectors.
    2. Select Add, then enter:
      • Group: Log Streaming (the App Connector Group you created in Step 1)
      • Enrollment Tokens: add the token generated in Step 3 (for example, DVQXP – NF69H)
      Select Add, then select Save.

Note: If the generated token is not working or has expired, repeat Step 3 to generate a new one.

  1. Confirm that the App Connector appears in the list.

Task 3.2 Add a Log Receiver ▾

In this task, you create a log receiver to stream User Activity logs to the syslog server in the data center.

  1. Access the log streaming settings. On the Corp Client PC 1 VM, go to Data Explorer > Log Streaming > Log Receivers.
  2. Configure the log receiver.
    1. Select Add Log Receiver on the Log Receivers page.
    2. Enter the following settings on the General tab (the first step of the wizard):
      • Name: Syslog-UserActivity
      • Domain or IP Address: siem.patraining.safemarch.com
      • TCP Port: 514
      • App Connector Groups: Log Streaming
    3. Select Next.
    4. Enter the following settings on the Log Selection tab:
      • Log Type: User Activity
      • Log Template: CSV
      • Log Stream Content: leave at the default values
    5. Select Next.
  3. Filter specific logs and save the receiver.
    1. On the Policy tab, leave the default settings, then select Next.
    2. On the Review page, review the configuration, then select Save.

Task 3.3 Add SSH Access to the SIEM Server ▾

In this task, you create an application segment and access policy to allow SSH access to the SIEM server for log verification.

Note: Use the skills you practiced in Lab 2 to complete this configuration.

  1. Configure an application segment for SSH access.
    1. On the Corp Client PC 1, go to Policies > Private Applications > Defined Application Segments.
    2. Create a segment with the following settings:
      • Name: SSH to SIEM
      • Applications: siem.patraining.safemarch.com
      • Default Port Ranges: SSH
    3. Select Next.
    4. Segment Group: CorpApps
    5. Server Group: CorpServers
    6. Select Save.
  2. Configure an access policy. Select Edit Policy and create a rule to allow SSH access to the SIEM server for your user account (for example, Allow SSH to SIEM).

Task 3.4 Verify the Log Feed ▾

In this task, you monitor the syslog file on the SIEM server to verify that the Zscaler log feed is active.

  1. Sign in to Zscaler Client Connector (ZCC).
    1. On the Corp Client PC 1, in the Windows taskbar (bottom-right corner), click the Show hidden icons arrow (^).
    2. Select the Zscaler Client Connector icon, then click Open Zscaler.
    3. On the Zscaler Client Connector login page, authenticate with the student credentials you use to sign in to the console.
    4. Select Sign in.
    5. Verify the service entitlement access for Internet Security and Private Access.
  2. Establish an SSH connection to the SIEM server.
    1. On the Corp Client PC 1, open a command prompt.
    2. Connect to the SIEM server: ssh zscaler@siem.patraining.safemarch.com
    3. When prompted, enter the password: Zscaler123!
    4. If prompted, enter yes to accept the host key.
  3. Monitor the log feed.
    1. Enter the following command to view the live syslog feed: tail -f /var/log/syslog
    2. Verify that log entries appear that include User Activity zpa-lss after the time field.

Note: If no entries appear, generate user activity by refreshing the HVAC application page you tested in Lab 2.

Note: Type exit in the command prompt to close the connection to the SIEM server.
