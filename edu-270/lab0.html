OVERVIEW

Welcome to Zscaler Zero Trust Automation (EDU-270). This is a guided, hands-on lab that moves you from clicking through the Zscaler console to automating it — through Postman/ZIdentity, the official Python SDK, and Terraform. All exercises run in a safe, read-only-by-default lab tenant. By the end of this lab you will be able to:

  • Access your assigned Skytap POD and launch the Corp: Client PC
  • Identify the two portals used throughout the course — Experience Center (configure) and Skytap (run & validate VMs)
  • Know where your lab credentials and the downloadable Lab Guide live
Course: EDU-270
Rev: 3.0 · Aug 2026
Platform: Skytap + Postman + VS Code + Zscaler Experience Center

What this course covers

Across the labs, your objectives include:

  • Fork a Postman collection, create a ZIdentity API client, and generate an access token (Lab 1)
  • Automate ZIA URL filtering and SSL inspection rules with the Zscaler Python SDK (Lab 2)
  • Automate ZCC app profiles, forwarding profiles, and device reporting with the SDK (Lab 3)
  • Automate a full ZPA access policy — connector group through application segment — with the SDK (Lab 4)
  • Declare and deploy ZIA rules with the Zscaler Terraform provider (Lab 5)
  • Declare and deploy ZPA segments and policies at scale with Terraform (Lab 6)

Lab Setup

This lab environment is designed for carrying out the exercises in this manual. Your lab environment tests secure programmatic access to Zscaler through the Zero Trust Exchange. Your virtual lab environment starts with:

  • A virtual Windows PC (Corp: Client PC) you use as the automation workstation — running Postman and Visual Studio Code
  • Credentials for the admin and API accounts you need
  • A lab manual with the set of exercises to guide your learning
Your POD ships with a Windows client VM, the credentials you need, and this lab manual — everything required to get from console clicks to code.

QUICK REFERENCE ▲
OneAPI
Zscaler's unified API gateway — one base URL and OAuth2 flow in front of ZIA, ZPA, and ZDX.
ZIdentity
Zscaler's identity platform; issues OAuth2 access tokens to API clients for OneAPI calls.
API Client
An OAuth2 client registered in ZIdentity with a Client ID/Secret and scoped resource access.
Access Token
A short-lived OAuth2 bearer token generated from client credentials, used on every API call.
Experience Center
console.zscaler.com — unified admin portal for ZIA, ZPA, ZDX, and API client management.
Skytap
Hosts the lab VMs (Corp: Client PC) for hands-on Postman / VS Code / Terraform work.
zscaler-sdk-python
Official Python SDK wrapping OneAPI/ZIA/ZPA/ZCC endpoints for scripted automation.
Terraform Provider
A plugin (zscaler/zia, zscaler/zpa) that translates HCL resources into OneAPI calls.
